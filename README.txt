LoL 2인 3팀 온라인 경매
========================
기능
- 2명만 입장
- 각자 3팀 운영
- 51명 선수 풀
- 랜덤 선수 등장, 중복 없음
- 각자 시작 포인트 30,000P
- 기본 최소 입찰 1P, 증가 100P
- 포지션별로 한 사람이 너무 많이 가져가 상대의 최소 3명을 확보할 수 없게 되는 입찰 자동 제한
  (탑 10명이면 한 사람 최대 7명, 정글 11명이면 최대 8명)
- 낙찰 선수는 보유 선수 목록에 들어감. 3팀에 최종 배치하는 것은 별도 단계로 남겨둠.
- 미낙찰 선수는 별도 미낙찰 목록에 쌓임.
- 본 경매가 끝난 뒤 '미낙찰 경매 시작'으로 미낙찰 선수만 따로 재경매 가능.
- 미낙찰 재경매에서 다시 미낙찰되면 목록에 다시 남음.

실행
1. Node.js 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 http://localhost:3000 접속

친구와 인터넷으로 같이 쓰려면 이 폴더를 Render/Railway/Fly.io 등의 Node 서버 호스팅에 올리면 됨.
